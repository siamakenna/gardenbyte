# GardenByte

GardenByte is a cozy React/Vite web toy that turns a first name into a symbolic watercolor garden. It maps name meaning, origin, mood, season, and time of day into flowers, crystals, garden features, colors, and a downloadable PNG.

## Live Demo

Play it now! https://gardenbyte-mu.vercel.app/

## Features

- Generate a personalized garden from a first name
- Choose mood, palette, season, time of day, and intensity
- Regrow the layout for new compositions
- Download the garden as a PNG
- Copy a caption or GitHub README snippet
- Uses a local starter dataset of name meanings and symbolic themes

## Tech Stack

- React
- Vite
- CSS
- SVG-generated garden artwork

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Vercel Settings

- Framework Preset: Vite
- Root Directory: `./`
- Install Command: `npm install`
- Build Command: `npm run build`
- Output Directory: `dist`
